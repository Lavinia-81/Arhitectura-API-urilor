# ARHITECTURA ȘI SECURITATEA API-URILOR MODERNE — Repository Oficial


Bun venit în repository-ul oficial al cărții „ARHITECTURA ȘI SECURITATEA API-URILOR MODERNE”, o lucrare tehnică dedicată dezvoltatorilor, arhitecților software și tuturor celor interesați de construcția, optimizarea și securizarea API-urilor moderne.

Acest repository servește ca material complementar pentru carte, oferind acces la:
- proiectul demonstrativ poezii-api, folosit în exemplele din carte
- setul complet de diagrame explicative ale capitolelor
- recomandare soluții pentru exercițiile din carte
- resurse vizuale și tehnice care ajută la înțelegerea arhitecturii unui API modern

Repository-ul este structurat editorial, clar și intuitiv, pentru a reflecta calitatea și rigoarea lucrării.

## Despre proiectul demonstrativ — poezii-api
Proiectul poezii-api este aplicația principală folosită în carte pentru a demonstra:
- arhitectura unui API modern
- routing, controllere, servicii și repository pattern
- integrarea Prisma și modelarea bazei de date
- caching, logging, rate limiting
- autentificare și autorizare
- bune practici de securitate
- deploy pe Render, PM2 și Docker, etc.
Codul este complet, curat, modular și reflectă standardele profesionale discutate în carte.
