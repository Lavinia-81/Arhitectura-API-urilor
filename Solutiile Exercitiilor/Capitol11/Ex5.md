Ex5. Schema Developer Portal-ului tău
Cerință: Desenează schema paginilor și funcțiilor.

-----

R => Structură profesionistă
```
Developer Portal
│
├── Dashboard
│     ├── Usage (daily, monthly)
│     ├── API Key status
│     └── Plan & limits
│
├── API Keys
│     ├── Generate key
│     ├── Revoke key
│     └── Regenerate key
│
├── Billing
│     ├── Current plan
│     ├── Upgrade/Downgrade
│     ├── Invoices
│     └── Payment methods
│
├── Documentation
│     ├── REST API
│     ├── Authentication
│     ├── Rate limiting
│     └── Webhooks
│
├── Playground
│     ├── Test requests
│     ├── Live response viewer
│     └── Code snippets
│
└── Support
      ├── Tickets
      ├── Status page
      └── Incident history
```

Funcții oferite utilizatorului
-> generare și management API Keys
-> vizualizare usage în timp real
-> upgrade plan
-> acces la documentație completă
-> testare API direct din browser
-> suport tehnic și status operational
