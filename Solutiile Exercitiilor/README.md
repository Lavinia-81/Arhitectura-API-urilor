# Soluțiile recomandate ale exercițiilor din cartea 
**ARHITECTURA ȘI SECURITATEA API-URILOR MODERNE**

Acest director conține soluțiile recomandate ale tuturor exercițiilor din carte.  
Fiecare capitol include rezolvări practice, complete, orientate spre producție, astfel încât cititorul să poată transforma teoria în implementări reale.

---

## Ce vei găsi aici
- soluții pentru toate exercițiile din capitolele 2–12  
- exemple de arhitectură pe straturi  
- implementări Fastify, Prisma, PostgreSQL, Redis  
- rate limiting avansat (Token Bucket, anti‑scraping, IP detection)  
- observabilitate completă (Prometheus, Grafana, OpenTelemetry, Jaeger)  
- CI/CD, containere, backup & restore  
- billing, planuri comerciale, Stripe Checkout  
- Developer Portal — structură și funcționalități  
- securitate avansată (HMAC, criptare AES‑256, roluri DB, WAF)
Acest folder este gândit ca un **laborator complet** pentru cititorii cărții.

---

## Important pentru cititori
Deși multe exemple sunt scrise în **TypeScript**, rog a se urmării **flow‑ul logic**, nu neapărat sintaxa.

### De ce?
Pentru că:
- principiile sunt universale  
- arhitectura pe straturi este aceeași în orice limbaj  
- rate limiting, caching, observabilitate, billing — toate au același flux conceptual  
- implementările pot fi transpuse ușor în Python, Go, Java, Rust, PHP, Ruby etc.
**Flow-ul este esențial. Sintaxa este doar un detaliu.**

## Scopul acestui repository
Acest folder nu este doar un set de rezolvări.  
Este un **ghid complet de implementare** pentru un API modern, sigur, scalabil, observabil și monetizabil.

Cititorul poate:
- să învețe arhitectura corectă  
- să implementeze un API real  
- să facă deploy în cloud  
- să adauge rate limiting, caching, securitate  
- să monitorizeze API-ul cu Prometheus + Grafana  
- să integreze OpenTelemetry + Jaeger  
- să implementeze billing și usage tracking  
- să creeze un Developer Portal complet
