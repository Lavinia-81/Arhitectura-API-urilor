## Important Notes for Readers

Many examples are written in **TypeScript**, but the focus should be on the **logical flow**, not the syntax.

### Why?

Because:

- the principles are universal  
- layered architecture is the same in any language  
- rate limiting, caching, observability, billing — all follow the same conceptual flow  
- implementations can be easily translated to Python, Go, Java, Rust, PHP, Ruby, etc.

**The flow is essential. Syntax is just a detail.**
