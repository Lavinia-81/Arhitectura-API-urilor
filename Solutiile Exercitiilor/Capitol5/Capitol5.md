# Capitolul 5 — Proiectul complet „poezii‑api”
Acest capitol nu conține exerciții de rezolvat.

Motivul este simplu: Capitolul 5 este un capitol special, dedicat unui proiect complet — **poezii‑api** — care servește ca studiu de caz real, complet, matur, construit pas cu pas.

---

## De ce nu există exerciții aici?
Pentru că întregul capitol este, în sine, un exercițiu practic extins:
- arhitectură pe straturi  
- validare  
- controlere  
- servicii  
- repository  
- rate limiting  
- caching  
- securitate  
- observabilitate  
- deploy  
- testare  
- bune practici
Este un exemplu de API cultural complet, construit de la zero, explicat în detaliu în carte.

## Recomandare pentru cititori
Deși unele exemple sunt scrise în **TypeScript**, te încurajez să urmărești **flow-ul arhitectural**, nu neapărat sintaxa.

Arhitectura corectă este aceeași în orice limbaj:
- Python  
- Go  
- Java  
- Rust  
- PHP  
- Ruby  
- Node.js  
Conceptul rămâne identic, indiferent de tehnologie.

---

## Concluzie
Capitolul 5 este un studiu de caz complet, nu un set de exerciții.  
Folosește-l ca referință practică pentru a înțelege cum arată un API modern, sigur, scalabil și bine structurat.
