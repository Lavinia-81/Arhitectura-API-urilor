Ex2. Scrie un Dockerfile pentru API-ul tău

-----

R => Dockerfile recomandat

FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
RUN npm run build
EXPOSE 3000
CMD ["node", "dist/index.js"]
-----

R => Build
docker build -t poezii-api .

-----

R => Run
docker run -p 3000:3000 poezii-api
-----

API-ul funcționează identic cu mediul local → containerizare este corectă.
