Ex1. Configurează un VPS (DigitalOcean) cu Ubuntu + Node.js + PM2 + Nginx

-----

R => 1. Instalare Node.js
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt install -y nodejs
-----


R => 2. Instalare PM2
bashsudo npm install -g pm2
-----


R => 3. Rulezi aplicația
pm2 start dist/index.js --name poezii-api
pm2 startup
pm2 save

-----

R => 4. Instalare Nginx
sudo apt install nginx -y
-----

R => 5. Configurare reverse proxy
Fișier: /etc/nginx/sites-available/api.conf

server {
    listen 80;
    server_name poezii-api.com;

    location / {
        proxy_pass http://localhost:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
-----

Activezi:

sudo ln -s /etc/nginx/sites-available/api.conf /etc/nginx/sites-enabled/
sudo systemctl restart nginx

API-ul tău rulează acum pe VPS, cu PM2 + Nginx.
