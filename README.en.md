# MODERN API ARCHITECTURE & SECURITY — Official Repository

Welcome to the official repository of the book **“Modern API Architecture & Security”**, a technical work dedicated to developers, software architects, and anyone interested in designing, optimizing, and securing modern APIs.

This repository serves as the companion resource for the book, providing access to:

- the **poezii‑api** demo project used throughout the chapters  
- the complete set of **architectural and explanatory diagrams**  
- **recommended solutions** for the exercises in the book  
- visual and technical resources that support the understanding of modern API architecture  

The repository is structured clearly and editorially, reflecting the quality and rigor of the published work.

## About the Demo Project — poezii‑api  
The **poezii‑api** project is the main application used in the book to demonstrate:

- modern API architecture  
- routing, controllers, services, repository pattern  
- Prisma integration & database modeling  
- caching, logging, rate limiting  
- authentication & authorization  
- security best practices  
- deployment on Render, PM2, Docker  

The codebase is clean, modular, and aligned with the professional standards presented in the book.
